Premium zodiac Compatibility Test with element-based scoring, relationship breakdown meters, strengths, challenges and advice.

== Description ==

Drop the shortcode `[compatibility_test]` on any page or post. Aliases: `[zodiac_compatibility]`, `[love_compatibility]`.

Features:
* Pick two zodiac signs (+ optional names) via clean dropdowns
* Element-based compatibility engine (Fire/Earth/Air/Water matrix) with animated score ring
* Element Connection analysis for the pairing
* Relationship breakdown meters: Love & Romance, Communication, Trust, Passion, Long-term Potential
* Strengths and "Watch Out For" lists tailored to the match band
* Personalised relationship advice
* Confetti, WhatsApp/Twitter/Save/Copy share, related tools, live counter
* Mobile-first, no jQuery, 100% client-side
* JavaScript delivered via wp_enqueue_script (footer) so wpautop never breaks it
* No FAQ block (so it never duplicates your own SEO content)

== Installation ==

1. Upload the `compatibility-test` folder to `/wp-content/plugins/` or upload the ZIP via Plugins -> Add New.
2. Activate the plugin in WordPress.
3. Add `[compatibility_test]` to any page, post, or widget.
