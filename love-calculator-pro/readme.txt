Premium Love Calculator with animations, golden hints, personalized advice, share cards, FAQ schema, and related tools.

== Description ==

Drop the shortcode `[love_calculator]` on any page or post.

Features:
* Live animated avatars
* Multi-factor compatibility algorithm (letter overlap + numerology + length harmony + seeded random)
* 4 compatibility metric bars (Trust, Chemistry, Communication, Long-term)
* Golden Hints box with score-specific advice
* Personalized AI-style love advice with tag chips
* Confetti celebration for scores 70%+
* WhatsApp / Twitter / Save / Copy share buttons
* FAQ accordion with FAQPage JSON-LD schema
* Score levels reference + related tools grid
* Live user counter with Indian comma formatting
* Mobile-first (375px), 48px+ touch targets
* No jQuery, no external dependencies

== Installation ==

1. Upload the `love-calculator-pro` folder to `/wp-content/plugins/` or upload the ZIP via Plugins -> Add New.
2. Activate the plugin in WordPress.
3. Add `[love_calculator]` to any page, post, or widget.
