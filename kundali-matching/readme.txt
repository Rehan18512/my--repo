Premium Vedic Kundali Matching (Ashtakoot Guna Milan) by name with all 8 kootas scored out of 36, dosha checks, verdict and remedies.

== Description ==

Drop the shortcode `[kundali_matching]` on any page or post. Aliases: `[kundali_matching_by_name]`, `[kundli_matching]`.

Features:
* Two-name input (boy & girl) with derived Rashi (moon sign) and Nakshatra
* Full Ashtakoot Guna Milan: Varna, Vashya, Tara, Yoni, Graha Maitri, Gana, Bhakoot, Nadi
* Animated total Guna score out of 36 with verdict (Excellent / Very Good / Acceptable / Needs Consideration)
* Itemised koota table showing points scored vs maximum, colour-coded pass/partial/fail
* Dosha checks: Manglik, Nadi and Bhakoot, with cancellation logic
* Conclusion + traditional guidance and remedies
* Confetti, WhatsApp/Twitter/Save/Copy share, related tools, live counter
* Mobile-first, no jQuery, 100% client-side
* JavaScript delivered via wp_enqueue_script (footer) so wpautop never breaks it
* No FAQ block (so it never duplicates your own SEO content)

== Installation ==

1. Upload the `kundali-matching` folder to `/wp-content/plugins/` or upload the ZIP via Plugins -> Add New.
2. Activate the plugin in WordPress.
3. Add `[kundali_matching]` to any page, post, or widget.
