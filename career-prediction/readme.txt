Premium Career Prediction tool combining sun-sign astrology and numerology life path to map career strengths, best fields and lucky stats.

== Description ==

Drop the shortcode `[career_prediction]` on any page or post. Aliases: `[career_prediction_by_dob]`, `[career_astrology]`.

Features:
* Date-of-birth input (+ optional name) with instant sun-sign + numerology life-path analysis
* Animated "Career Power" score ring (consistent for the same birth date)
* Best Career Fields tailored to your zodiac element
* Numerology Life Path card (1-9 plus master numbers 11/22/33)
* Career strength meters: Leadership, Creativity, Analytical Mind, Communication
* Ideal Work Environment description + trait tags
* Power Color (swatch), Lucky Number, Power Day, Lucky Direction
* Golden Career Tips, confetti, WhatsApp/Twitter/Save/Copy share
* Related tools grid, live counter, mobile-first, no jQuery
* JavaScript delivered via wp_enqueue_script (footer) so wpautop never breaks it
* No FAQ block (so it never duplicates your own SEO content)

== Installation ==

1. Upload the `career-prediction` folder to `/wp-content/plugins/` or upload the ZIP via Plugins -> Add New.
2. Activate the plugin in WordPress.
3. Add `[career_prediction]` to any page, post, or widget.
