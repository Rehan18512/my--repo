Premium Love Message Generator with occasion picker, tone selector, name personalization, an elegant message card and one-tap copy & share.

== Description ==

Drop the shortcode `[love_message_generator]` on any page or post.

Features:
* Optional recipient name with smart personalization (graceful "my love" fallback)
* 8 occasions: Romantic, Good Morning, Good Night, Miss You, Anniversary, Long Distance, Apology, Flirty
* 4 tones: Sweet, Poetic, Playful, Deep
* 200+ hand-written message templates (every occasion x tone combination covered)
* Elegant gradient message card with occasion & tone badges
* "Another Message" regenerate (never repeats the same one twice in a row)
* Copy / WhatsApp / Twitter / Save share buttons (shares the actual message text)
* Confetti celebration + related tools grid
* Live counter with Indian comma formatting
* Mobile-first (375px), 48px+ touch targets
* No jQuery, no external dependencies, 100% client-side
* No FAQ block (so it never duplicates your own SEO content)

== Installation ==

1. Upload the `love-message-generator` folder to `/wp-content/plugins/` or upload the ZIP via Plugins -> Add New.
2. Activate the plugin in WordPress.
3. Add `[love_message_generator]` to any page, post, or widget.
