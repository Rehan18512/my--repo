Premium daily Love Horoscope with zodiac picker, animated love score, lucky color/number/time, best-match sign, mood meters, singles & couples advice and share cards.

== Description ==

Drop the shortcode `[love_horoscope]` on any page or post.

Features:
* 12 zodiac signs with one-tap selection
* Animated daily "Love Energy" score ring (consistent per sign per day)
* Lucky Color (with swatch), Lucky Number, Lucky Time, Best Match sign
* Singles vs Couples advice toggle
* 4 mood meter bars (Romance, Passion, Harmony, Communication)
* Today's Golden Love Tips, personalized per sign
* Confetti celebration on high-energy days
* WhatsApp / Twitter / Save / Copy share buttons
* Quick-jump "All 12 Signs" reference grid + related tools
* Live readings counter with Indian comma formatting
* Mobile-first (375px), 48px+ touch targets
* No jQuery, no external dependencies, 100% client-side
* No FAQ block (so it never duplicates your own SEO content)

== Installation ==

1. Upload the `love-horoscope-today` folder to `/wp-content/plugins/` or upload the ZIP via Plugins -> Add New.
2. Activate the plugin in WordPress.
3. Add `[love_horoscope]` to any page, post, or widget.
