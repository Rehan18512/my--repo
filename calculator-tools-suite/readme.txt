Three premium, animated, SEO-friendly calculators in one plugin — Friendship, Mulank & Bhagyank, and Crush — with Hindi/English toggle, Advanced mode, golden hints and downloadable result cards.

== Description ==

A single lightweight plugin that gives you three unique, fully animated calculators that share one polished golden + royal theme. No jQuery, no external libraries, fully client-side and privacy-first.

Shortcodes:

* `[friendship_calculator]` — Friendship Calculator
* `[mulank_calculator]` — Mulank & Bhagyank (numerology) Calculator
* `[crush_calculator]` — Crush Calculator

Shared features across all three tools:

* Hindi + English language toggle (EN / हिंदी)
* Advanced mode with an extra detailed report
* One unified animated theme (consistent colors everywhere)
* Animated loading rings, count-up score, progress ring & metric bars
* Golden Hints box + personalized advice with tag chips
* Confetti celebration on high scores
* WhatsApp / Twitter share + Copy link
* Download result as a branded PNG card (canvas, no external library)
* SoftwareApplication JSON-LD schema for SEO (no FAQ schema — add your own FAQ content on the page)
* Number / level reference grid + related-tools grid
* Mobile-first, 48px+ touch targets, reduced-motion support
* No FAQ block inside the tool, so it never duplicates the FAQ content on your page

Friendship Calculator highlights:

* Multi-factor score (letter overlap + numerology + length harmony + seeded random)
* Loyalty / Understanding / Fun / Long-term bond meters
* Best Friendship Emoji, Dream-Team Career, Perfect Pet, and your Anthem song
* Advanced: compatibility number, shared element, best hangout, ideal gift, bond forecast

Mulank & Bhagyank Calculator highlights:

* Calculates Mulank (root number from the birth day) and Bhagyank (destiny number from the full date)
* Ruling planet, archetype, personality reading
* Lucky color, lucky day, lucky/friendly numbers, lucky gemstone
* Golden tips & remedies, keywords, guidance
* Advanced: direction, element, friendly/challenging numbers, beej mantra, ideal careers

Crush Calculator highlights:

* Crush match score with Attraction / Chemistry / Connection / Spark meters
* Love Emoji, Future Prediction, Soulmate Sign, Today's Love Horoscope
* Golden hints + advice
* Advanced: compatibility number, love element, who should move first, ideal first date, confession odds, lucky day

== Installation ==

1. Upload the `calculator-tools-suite` folder to `/wp-content/plugins/` or upload the ZIP via Plugins -> Add New -> Upload Plugin.
2. Activate "Calculator Tools Suite" in WordPress.
3. Add any of these shortcodes to a page, post, or widget:
   * `[friendship_calculator]`
   * `[mulank_calculator]`
   * `[crush_calculator]`

You can place all three on the same site (e.g. one per page). The shared theme + scripts load only once per page automatically.

== Frequently Asked Questions ==

= Does it slow down my site? =
No. There is no jQuery and no external library. Shared CSS/JS print only once per page.

= Is user data stored? =
No. Everything is calculated in the browser. Nothing is sent to a server or saved.

= Can I show the tool in Hindi? =
Yes. Each tool has an EN / हिंदी toggle in the top-right.
