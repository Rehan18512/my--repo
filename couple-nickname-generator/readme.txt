Premium Couple Nickname Generator that blends two names into ship names, cute pet names, stylish combos and romantic nicknames, each with a vibe label and one-tap copy.

== Description ==

Drop the shortcode `[couple_nickname_generator]` on any page or post.

Features:
* Two-name input with live animated avatars
* 4 categories, 40+ ideas total: Ship Names, Cute Nicknames, Stylish Combos, Romantic Pet Names
* Every nickname has a "vibe" label (Romantic, Playful, Trendy, Aesthetic...)
* One-tap copy on any nickname chip with copied confirmation
* "Top Pick" highlight + "More Ideas" regenerate button for fresh variants
* Confetti celebration on results
* WhatsApp / Twitter / Save / Copy share buttons
* Related tools grid
* Live counter with Indian comma formatting
* Mobile-first (375px), 48px+ touch targets
* No jQuery, no external dependencies, 100% client-side
* No FAQ block (so it never duplicates your own SEO content)

== Installation ==

1. Upload the `couple-nickname-generator` folder to `/wp-content/plugins/` or upload the ZIP via Plugins -> Add New.
2. Activate the plugin in WordPress.
3. Add `[couple_nickname_generator]` to any page, post, or widget.
